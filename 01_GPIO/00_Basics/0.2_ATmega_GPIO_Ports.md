# ATmega2560 GPIO Ports

The **ATmega2560** is a microcontroller that provides multiple **GPIO (General-Purpose Input/Output) pins**.

These GPIO pins are grouped into **ports**. Each port contains multiple pins that can be configured as either **input** or **output**.

## GPIO Ports in ATmega2560

| Port | Pins |
|------|------|
| PORTA | PA0 – PA7 |
| PORTB | PB0 – PB7 |
| PORTC | PC0 – PC7 |
| PORTD | PD0 – PD7 |
| PORTE | PE0 – PE7 |
| PORTF | PF0 – PF7 |
| PORTG | PG0 – PG5 |
| PORTH | PH0 – PH7 |
| PORTJ | PJ0 – PJ7 |
| PORTK | PK0 – PK7 |
| PORTL | PL0 – PL7 |

## GPIO Pin Names

Each GPIO pin has a name based on its port and pin number.

For example:

- `PA0` → Port A, Pin 0
- `PB3` → Port B, Pin 3
- `PC7` → Port C, Pin 7
- `PL5` → Port L, Pin 5

## GPIO Registers

Each port is controlled using three main registers:

- **DDRx** → Sets the pin as Input or Output
- **PORTx** → Writes output value or enables the internal pull-up resistor
- **PINx** → Reads the pin's input value

Here, `x` represents the port letter.
