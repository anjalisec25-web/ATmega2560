# What is GPIO?

**GPIO (General-Purpose Input/Output)** is a set of programmable pins on a microcontroller or processor that can be configured to either **receive input signals** or **send output signals**.

### GPIO can be used as:

- **Input** → To read signals from devices such as switches and sensors.
- **Output** → To control devices such as LEDs, buzzers, and relays.

### Simple Example

A GPIO pin can:

- Read a button → **Input**
- Control an LED → **Output**
