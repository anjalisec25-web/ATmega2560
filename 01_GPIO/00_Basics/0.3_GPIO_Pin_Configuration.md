# GPIO Pin Configuration

## What is Pin Configuration?

GPIO pin configuration means setting a GPIO pin to work as either an **input** or an **output**.

## 1. Input Configuration

The pin is configured as an **input** when the microcontroller needs to **read** a signal.

Examples:
- Push button
- Switch

```text
Input Pin → Microcontroller reads the signal

## 2. Output Configuration

An output pin is used when the microcontroller needs to **send a digital signal** to control an external device.

### Working

```text
Microcontroller → GPIO Pin → External Device
