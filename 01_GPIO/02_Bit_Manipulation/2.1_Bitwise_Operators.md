# Bitwise Operators

Bitwise operators are used to perform operations on individual bits of a value.

They are commonly used in **embedded systems, microcontrollers, GPIO, and register manipulation**.

## Types of Bitwise Operators

| Operator | Name |
|----------|------|
| `&` | AND |
| `|` | OR |
| `^` | XOR |
| `~` | NOT |
| `<<` | Left Shift |
| `>>` | Right Shift |

## Basic Uses

- `&` → Used to **check bits**
- `|` → Used to **set bits**
- `^` → Used to **toggle bits**
- `~` → Used to **invert bits**
- `<<` → Used to **shift bits left**
- `>>` → Used to **shift bits right**
