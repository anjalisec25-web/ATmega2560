# Read Bit

## Definition

**Read Bit** is used to check whether a specific bit in a binary number or register is **0 or 1** without modifying the original value.

In ATmega2560, Read Bit is useful for checking the status of **input pins and register bits**.

## Operator Used

The **AND (`&`)** operator is used to read a specific bit.

## Syntax

value & (1 << position)

## Example

check bit 5 of PINB.

PINB & (1<<3)

Check multiple bits of PINB.

(PINB & ((1 << 5) | (1 << 3))) == ((1 << 5) | (1 << 3))
