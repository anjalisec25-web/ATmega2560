# Set Bit

## Definition

Setting a bit means changing a specific bit from `0` to `1`.

---

## Operator Used

The **Bitwise OR (`|`)** operator is used to set a bit.

### Syntax

value = value | (1 << position);

or,

value |= (1 << position);

## Example

Set bit 5 of a PORT B register.

PORTB |= (1 << 5);

Multiple bits can be set using OR.

PORTB |= (1 << 5) | (1 << 3) | (1 << 1);
