# Toggle Bit

Toggle operation changes a bit from one state to the opposite state.

- `0 → 1`
- `1 → 0`

## Operator Used

The **XOR (`^`) operator** is used to toggle a bit.

## Syntax

num = num ^ (1U << position);

or, 

num ^= (1U << position);

## Example

Toggle Bit 5 of Port B register.

PORTB ^= (1U << 5);

Toggle multiple Bits of Port B.

PORTB ^= (1U << 5) | (1U << 4) | (1U << 3) | (1U << 1);
